# Navi Evaluation Framework

This directory contains the evaluation framework for Navi, inspired by Codebuff's evaluation methodology.

## Structure

*   `tasks/`: Standardized coding tasks used for evaluation.
    *   `bug-fixes/`: Scenarios requiring bug identification and repair.
    *   `refactoring/`: Tasks focused on code restructuring and improvement.
    *   `features/`: Requests for new feature implementation.
    *   `security/`: Security vulnerability discovery and patching.
*   `benchmarks/`: Performance benchmark configurations and results.
*   `metrics/`: Definitions of success/failure metrics.
*   `datasets/`: Test datasets used by tasks.
